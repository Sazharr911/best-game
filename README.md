EMBERFALL is a neon arena defense shooter. You are the lone warden of the Ember Reactor, a glowing landmark at the arena's center, and wraith silhouettes converge on it in escalating waves. Kills build the Ember Chain — a multiplier that arcs visibly between kills and feeds the reactor — and the chain shatters the moment the reactor takes damage. Between waves you pick one of three upgrades that visibly transform your shot, your dash or the reactor itself. On wave 5 the Embermaw comes for the core: destroy it and the core ignites. WASD or arrows move, the mouse aims, hold the mouse (or toggle auto-fire with F) to shoot, Shift or Space dashes, M mutes. Vanilla JavaScript and Canvas 2D, WebAudio-synthesized sound, no build step and no external assets.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. To produce the hand-in output instead, run `MAKEFUN_OUTPUT_DIR=out node main.ts` from the repository root.
